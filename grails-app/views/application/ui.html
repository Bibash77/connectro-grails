Elasticsearch API UI

1. Average Rating by City (GET)

Displays the average rating of companies grouped by city.

2. Year-wise Company Creation Histogram

Displays the number of companies created per year, optionally filtered.

3. Rating-wise Stats

Shows average, min, max ratings grouped by category.

4. Cardinal Tags Filtered (Fetch tags overview over the range period of time)

Displays tags based on selected cities and date range.

5. City-wise Top N Records Filtered

Get the top N rated companies in each city based on optional filters such as category, verification, and cost threshold.
